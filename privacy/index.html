Política de privacidad

Última actualización: 19 de agosto de 2026.

1. Responsable y alcance

Esta Política de privacidad describe el tratamiento de datos asociado a Sopalux, una aplicación de sopa de letras desarrollada dentro de NeuroNova Apps. La política cubre la demostración web pública y servirá como referencia para la versión Android mientras sus prácticas de datos sean las aquí descritas. Si la aplicación incorpora nuevas funciones, permisos, servicios o SDKs que cambien el tratamiento de datos, esta política será actualizada antes de su distribución correspondiente.

2. Datos que Sopalux solicita actualmente

La versión pública actual de Sopalux no requiere crear una cuenta ni solicita nombre, dirección, número de teléfono, correo electrónico, ubicación, contactos, fotografías, archivos, información financiera, datos de salud ni otros datos personales o sensibles para utilizar la demostración del juego.

3. Datos de juego y almacenamiento local

La demostración web puede utilizar únicamente información necesaria para ejecutar la partida durante la sesión, como palabras encontradas, selección de casillas y progreso del tablero. Actualmente esta información no se utiliza para identificar al usuario ni se envía a un servidor propio de Sopalux. Si en una versión posterior se guarda progreso mediante almacenamiento local del dispositivo, ese almacenamiento se utilizará exclusivamente para funciones de la aplicación y se documentará de forma coherente con la sección de Seguridad de los datos de Google Play.

4. Recopilación, uso y compartición de datos

Con el funcionamiento actual, Sopalux no recopila deliberadamente datos personales o sensibles a través de formularios de registro, perfiles o cuentas, y no vende datos personales. Tampoco comparte deliberadamente datos personales con terceros con fines publicitarios. Cualquier futura integración que implique recopilación, uso o compartición de datos será declarada de forma expresa en esta política y en Google Play antes de su publicación.

5. Servicios y recursos de terceros

La web de Sopalux se publica mediante infraestructura de GitHub Pages y puede cargar recursos compartidos del ecosistema NeuroNova Apps, como componentes de accesibilidad. Estos proveedores pueden tratar información técnica necesaria para entregar sus servicios conforme a sus propias políticas y condiciones. Antes de publicar una versión Android en Google Play, NeuroNova Apps revisará los SDKs y servicios incorporados para que la declaración de Seguridad de los datos coincida con el comportamiento real de la aplicación.

6. Permisos del dispositivo

La demostración web no solicita permisos sensibles del dispositivo. Si una futura versión Android requiere permisos adicionales, estos se limitarán a funciones necesarias para la experiencia de Sopalux y se informarán de manera clara antes o en el momento en que corresponda solicitar el acceso.

7. Seguridad

NeuroNova Apps procura minimizar el tratamiento de datos y limitarlo a lo necesario para las funciones ofrecidas. Cuando en el futuro se incorporen datos persistentes o servicios remotos, se aplicarán medidas técnicas y organizativas razonables para proteger la información frente a acceso, alteración, divulgación o pérdida no autorizados.

8. Conservación y eliminación

Actualmente Sopalux no mantiene una base de datos propia de cuentas de usuario ni conserva datos personales proporcionados por el jugador. Los datos temporales de la sesión de juego dejan de ser necesarios al finalizar o reiniciar la experiencia. Si se incorporan cuentas, sincronización u otros datos persistentes, esta sección se actualizará para explicar los plazos de conservación y el mecanismo de eliminación aplicable.

9. Cuentas de usuario

Sopalux no ofrece actualmente creación de cuentas. Por ello, no existe en este momento información de cuenta que deba solicitarse para su eliminación. Si en el futuro se habilitan cuentas, se ofrecerá un mecanismo claro y accesible para solicitar su eliminación junto con los datos asociados, conforme a los requisitos aplicables de Google Play.

10. Menores de edad

Sopalux está concebido como un juego de palabras de uso general y no solicita deliberadamente datos personales a menores. Si una futura versión se dirige específicamente a niños o incorpora funciones que impliquen tratamiento de datos de menores, se revisará esta política y la configuración de Google Play para cumplir los requisitos aplicables a esa audiencia.

11. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones, permisos, SDKs, servicios o prácticas de datos de Sopalux. La versión vigente mostrará su fecha de última actualización en esta misma página.

12. Contacto sobre privacidad

Para consultas relacionadas con privacidad, tratamiento de datos o esta política, puedes contactar a NeuroNova Apps mediante el correo: berm_km@hotmail.com.

13. Relación con Google Play

Cuando Sopalux sea publicado en Google Play, la información declarada en la sección Seguridad de los datos de Play Console deberá mantenerse coherente con esta política y con el funcionamiento real de la aplicación. La política estará disponible públicamente mediante una URL accesible y también deberá ser accesible desde la propia aplicación Android.
